## Model-call cost estimate

Prices are USD per million input/output tokens, checked against the [OpenRouter model catalog](https://openrouter.ai/docs/api/api-reference/models/get-models) and [ZDR endpoint list](https://openrouter.ai/docs/api/api-reference/endpoints/list-endpoints-zdr) on 2026-09-27: Gemini standard `google-vertex/global` **$0.50/$3.00** (flex was $0.25/$1.50), Sonnet `google-vertex/global` **$2.00/$10.00**, and Grok `xai/zdr` **$1.25/$2.50**. Recheck the pinned endpoints, availability, and rates before approval and before execution. Do not estimate from the shared key-level balance change.

The 150-case dev NLU measurements averaged **1,699 input / 138 output tokens** for Gemini and **2,689 / 319** for Sonnet. To cover longer final conversations and schema/provider variation, this plan uses **2,000/250** for Gemini NLU and **3,200/500** for Sonnet NLU. Phrasing has no comparable paid end-to-end measurement, so its estimates are deliberately higher and its count is an upper bound of one model draft per customer message; many response types use templates. The three-item judge smoke averaged **1,140 input / 40 output tokens**, while the plan uses **2,500/120**. These are planning assumptions, not measured final usage. The counts below exclude retries except for the contingency.
